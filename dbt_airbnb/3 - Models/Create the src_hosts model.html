Create the src_hosts model

Description

Create a model which builds on top of our raw_hosts table.

Estimated Duration: 20 minutes

Instructions

Create a model which builds on top of our raw_hosts table.

1) Name the model models/src/src_hosts.sql
2) Use a CTE to define an alias called raw_hosts. This CTE will select every column from the raw host table AIRBNB.RAW.RAW_HOSTS
3) In your final SELECT, select every column and record from raw_hosts and rename the following columns:

  • id to host_id

  • name to host_name

Questions and Solutions

Question 1

Please provide the SQL you came up with.

Solution

WITH raw_hosts AS ( 
  SELECT * FROM AIRBNB.RAW.RAW_HOSTS
)
SELECT
  id AS host_id,
  NAME AS host_name, is_superhost, created_at, updated_at
FROM
  raw_hosts
