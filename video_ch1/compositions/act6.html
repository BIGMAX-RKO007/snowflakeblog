🌲 Session 参数 3 级继承树
LEVEL 1 · 顶层基线
Account Parameter
全账户默认基准（如：默认 AUTO_SUSPEND、全局时区）
▼ 自动继承 / 按需定制覆盖
LEVEL 2 · 中间层
User Parameter
为特定运维/业务用户单独绑定的个性化设定
▼ 自动继承 / 会话动态覆盖
LEVEL 3 · 最底层 (最高优先级)
Session Parameter
应用连接执行 ALTER SESSION 动态生效的实时最终值
📌 规则：未显式配置时向下自动继承，显式配置时底层优先覆盖。
